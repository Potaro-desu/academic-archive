# Role looks, v1.3

The shared shell remains ISPSC-branded. Every role uses the existing palette:
ink `#203326`, paper `#f7f8f2`, green `#287044`, deep green `#1d5635`, gold
`#e4b526`, and alert red `#a63b37`. Manrope is used for headings and DM Sans
for body text. Red remains reserved for destructive actions and alerts.

## Shared shell

- White sticky header with the existing ISPSC mark and navigation.
- Existing footer, resource status chips and page content.
- A 3px gold `#e9bd67` focus outline remains visible for keyboard navigation.
- Shared page spacing, card radius and responsive behavior.
- No role-specific styling on the public catalog, resource detail, login or
  registration pages.

## Admin, Control Center

- Hero: full-width deep green `#1d5635` band, white heading and a 3px gold rule
  at the bottom. Keep the existing eyebrow, heading, intro and primary action.
- Buttons: solid deep green with gold hover and ink text. Existing destructive
  buttons remain red.
- Stats: compact cards with gold top rules, gold figures and a denser grid.
- Tables: compact row padding, deep green column headings and gold row hover.
- Dashboard order: review queue, archive overview, user-directory and audit-log
  shortcuts, then shared notifications and favorites.
- Empty states retain existing words and controls, with a formal compact
  presentation.
- The admin users and audit pages use the same dense table treatment.

## Faculty, Reading Room

- Hero: warm paper background, large green heading and gold underline beneath
  the greeting.
- Buttons: solid green with a gold underline on hover.
- Cards: roomy padding, generous whitespace and soft existing-style shadows.
- Review queue: card list with the existing student, resource and date details,
  plus one clear Review action per card.
- Section headings: small gold square marker.
- Empty states retain their existing copy and available action, with a calm
  card treatment.
- Faculty presentation applies to the faculty dashboard, own-submissions view,
  submit form and edit form. The shared Submit Resource and My Submissions pages
  use a pale yellow canvas for every role while retaining role-specific accents.

## Student, Study Desk

- Hero: bright paper background, large green greeting, a gold progress chip
  showing the existing submission total, and the existing primary action.
- Buttons: bright green with a gentle transform-only lift on hover.
- Cards: larger rounded surfaces, green file chips and the existing clear
  status badges.
- Dashboard order: My coursework, Browse published work, the existing
  how-it-works guide, then secondary totals and shared updates.
- Empty states retain their existing words and next-step action.
- Student presentation applies to the student dashboard, own-submissions view,
  submit form and edit form. The shared Submit Resource and My Submissions pages
  use a pale yellow canvas for every role while retaining role-specific accents.

## Public visitors

Public pages keep their existing content and structure. They receive only the
shared focus, spacing, font-loading and motion foundation.
